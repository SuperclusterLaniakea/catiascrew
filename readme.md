\# 螺母全面技术指南：标准、精度、尺寸计算与Python参数化绘图



\## 一、螺母的主要种类与标准体系



\### 1.1 按结构型式分类



螺母按结构型式主要分为以下几种：



| 类型 | 说明 | 典型标准 |

|------|------|----------|

| \*\*1型六角螺母\*\* | 最常用的标准螺母，高度约为0.8D | GB/T 6170、ISO 4032、DIN 934 |

| \*\*2型六角螺母\*\* | 高度较厚（约1.0D），用于高强度连接 | GB/T 6175、ISO 4033、DIN 970 |

| \*\*薄螺母（0型）\*\* | 高度最薄（约0.5D），用于双螺母防松或空间受限场合 | GB/T 6172、ISO 4035 |

| \*\*六角法兰面螺母\*\* | 带法兰盘，增大接触面积，防松性能好 | GB/T 6177.1、DIN 6923 |

| \*\*锁紧螺母\*\* | 含非金属嵌件或全金属锁紧结构 | GB/T 6183.1（非金属嵌件）、GB/T 6185.1（全金属） |

| \*\*圆螺母\*\* | 圆柱形带槽，用于轴承锁紧 | GB/T 812、GB/T 810 |

| \*\*方螺母\*\* | 方形外轮廓，用于槽钢等特殊场合 | GB/T 39 |

| \*\*盖形螺母\*\* | 顶部封闭，保护螺纹端部 | GB/T 923 |



\*\*1型六角螺母\*\*是应用最广泛的标准螺母，分为A、B、C三个产品等级。\*\*2型六角螺母\*\*的厚度更厚，适用于需要更高承载能力的连接场合。\*\*锁紧螺母\*\*通过非金属嵌件（尼龙圈）或全金属变形结构实现防松功能。\*\*法兰螺母\*\*底部带有法兰盘结构，可分散压力并具备一定的防松效果。



\### 1.2 主要标准体系对照



| 标准体系 | 常用标准号 | 适用范围 |

|----------|-----------|----------|

| \*\*中国GB\*\* | GB/T 41（C级）、GB/T 6170（A/B级）、GB/T 6175（2型） | 国内通用 |

| \*\*国际ISO\*\* | ISO 4032（1型）、ISO 4033（2型）、ISO 4035（薄型） | 国际贸易 |

| \*\*德国DIN\*\* | DIN 934（1型）、DIN 970（2型）、DIN 439（薄型） | 欧洲体系 |

| \*\*美国ASTM\*\* | ASTM A194/A194M（高温高压用）、ASTM A563 | 美洲体系 |

| \*\*美国ASME\*\* | ASME B18.2.2（方螺母和六角螺母） | 美洲体系 |



ASTM A194/A194M涵盖了碳钢、合金钢和马氏体不锈钢螺母，尺寸范围为1/4\~4英寸和公制M6\~M100。ISO 4032规定了1型六角螺母的特性，螺纹范围从M1.6到M64，当螺纹直径D≤M16时精度等级为A级，D>M16时为B级。





\## 二、精度等级体系



\### 2.1 产品等级（A、B、C级）



产品等级由公差大小确定，\*\*A级最精确，C级最不精确\*\*：



\- \*\*A级\*\*：用于螺纹直径D≤M16的螺母，适用于精度要求高的机器设备

\- \*\*B级\*\*：用于螺纹直径D>M16的螺母，适用于中等精度场合

\- \*\*C级\*\*：用于表面较粗糙、精度要求不高的结构，如建筑钢结构



GB/T 41规定的C级六角螺母，螺纹公差为7H级，机械性能等级为D≤M16时5级，M16<D≤M39时4\~5级。



\### 2.2 螺纹精度等级（6H/6G）



螺母的螺纹精度等级是指内螺纹的公差带位置和公差等级：



\- \*\*6H\*\*：中等精度内螺纹，基本偏差为H（下偏差为零），用于不经镀层的螺母

\- \*\*6G\*\*：中等精度内螺纹，基本偏差为G（有正的下偏差），用于镀前螺纹，镀层厚度通常为6\~9μm



对于精制紧固件螺纹，标准推荐采用\*\*6H/6g\*\*的配合（螺母6H，螺栓6g）。镀前螺母采用6G级，镀后达到6H级。



\*\*优选公差带\*\*：中等精度内螺纹推荐6H（粗体优先），其次5H；精密级为4H\~5H。



\### 2.3 性能等级



螺母性能等级与螺栓匹配使用，常见等级包括：



| 性能等级 | 适用螺母类型 | 匹配螺栓等级 |

|----------|------------|------------|

| 4、5级 | C级螺母 | 4.6、4.8、5.6、5.8 |

| 8级 | 1型A/B级螺母 | 8.8 |

| 9级 | 2型螺母 | 9.8 |

| 10级 | 2型螺母 | 10.9 |

| 12级 | 2型螺母 | 12.9 |

| A2-70/A4-80 | 不锈钢螺母 | 不锈钢螺栓 |





\## 三、尺寸计算与公称尺寸



\### 3.1 关键尺寸参数



六角螺母的核心尺寸参数包括：



\- \*\*D\*\*：螺纹公称直径

\- \*\*P\*\*：螺距

\- \*\*s\*\*：对边宽度

\- \*\*e\*\*：对角宽度（外圆）

\- \*\*m\*\*：螺母厚度



\### 3.2 简化计算公式



根据工程实践经验，可归纳出以下近似计算方法：



\*\*对边宽度 s：\*\*

\- 当D为M5\~M10时：s ≈ D × 1.6

\- 当D为M12\~M27时：s ≈ D × 1.5

\- 当D为M30\~M36时：s ≈ D × 1.5 + 1

\- 当D为M42\~M48时：s ≈ D × 1.5 + 2



\*\*对角宽度 e：\*\*

\- e ≈ s / 0.9（对边宽度取整后计算）



\*\*螺母厚度 m（1型螺母）：\*\*

\- m ≈ D（近似等于螺纹公称直径）



\*\*说明\*\*：以上为近似关系，实际设计中应以具体标准表格为准。

\## 四、用AI + Python参数化绘制螺母



\### 4.1 工具链推荐



| 工具 | 特点 | 适用场景 |

|------|------|----------|

| \*\*CadQuery\*\* | Python原生CAD库，基于OCCT内核，支持STEP/STL导出 | 精确B-rep建模 |

| \*\*PyMADCAD\*\* | 轻量脚本CAD库，自带ISO螺母标准件库 | 快速原型 |

| \*\*FreeCAD + Python\*\* | 全功能CAD，通过Python API控制 | 完整设计流程 |

| \*\*yapCAD\*\* | 程序化CAD系统，含完整紧固件目录 | 自动化生成 |

| \*\*OpenSCAD + Python\*\* | 通过openscadpy库调用 | 3D打印件 |



CadQuery是推荐的首选工具，它提供了`cq\_warehouse`扩展库，内置了`fastenerNut`类，可以直接通过标准号和尺寸生成螺母模型。PyMADCAD同样内置了ISO螺母标准件库，支持螺纹几何的精确生成。



\### 4.2 向AI提问的Prompt模板



要让AI生成高质量的螺母绘制代码，建议使用以下结构化Prompt：



\*\*模板A — CadQuery方式：\*\*

```

请用Python的CadQuery库编写一个参数化六角螺母的建模脚本。

要求：

1\. 螺母规格：M12，标准：GB/T 6170（1型六角螺母）

2\. 尺寸参数：对边宽度s=18mm，对角宽度e=20.03mm，厚度m=10.8mm

3\. 中心孔为M12内螺纹，螺距1.75mm，公差等级6H

4\. 包含上下端面的倒角（约15°\~30°）

5\. 输出为STEP格式文件

6\. 代码中包含尺寸参数的变量定义，便于修改为其他规格

```



\*\*模板B — FreeCAD方式：\*\*

```

请生成FreeCAD Python控制台脚本，创建一个参数化六角螺母模型。

参数：螺纹公称直径D=12mm，对边宽度s=18mm，螺母厚度m=10.8mm。

要求：使用PartDesign工作台，先绘制正六边形草图并拉伸，再在中心创建螺纹孔。

```



\*\*模板C — 批量生成方式：\*\*

```

请编写一个Python脚本，使用CadQuery生成一个六角螺母族（M6、M8、M10、M12、M16、M20），

```



\### 4.3 CadQuery螺母建模核心代码示例



以下代码展示用CadQuery生成一个标准六角螺母的核心逻辑：



```python

import cadquery as cq

import math



def make\_hex\_nut(D, P, s, m, chamfer\_angle=30):

&#x20;   """

&#x20;   参数化生成六角螺母

&#x20;   D: 螺纹公称直径 (mm)

&#x20;   P: 螺距 (mm)

&#x20;   s: 对边宽度 (mm)

&#x20;   m: 螺母厚度 (mm)

&#x20;   chamfer\_angle: 倒角角度 (度)

&#x20;   """

&#x20;   # 计算六边形外接圆半径（对角宽度的一半）

&#x20;   R = s / math.sqrt(3)  # 对边到中心的距离

&#x20;   Rc = s / math.sqrt(3) \* 2  # 外接圆半径 = e/2



&#x20;   # 六边形顶点

&#x20;   pts = \[]

&#x20;   for i in range(6):

&#x20;       angle = math.radians(60 \* i)

&#x20;       x = Rc / 2 \* math.cos(angle)

&#x20;       y = Rc / 2 \* math.sin(angle)

&#x20;       pts.append((x, y))



&#x20;   # 创建六边形实体

&#x20;   nut = (cq.Workplane("XY")

&#x20;          .polygon(6, s / math.sqrt(3) \* 2)  # 六边形外接圆直径

&#x20;          .extrude(m)

&#x20;          )



&#x20;   # 中心螺纹孔（简化表示——圆柱孔，实际可用Helical thread）

&#x20;   nut = nut.faces(">Z").workplane().hole(D)



&#x20;   # 上下端面倒角

&#x20;   nut = nut.faces(">Z").edges().chamfer(0.5 \* P)

&#x20;   nut = nut.faces("<Z").edges().chamfer(0.5 \* P)



&#x20;   return nut



\# 生成M12螺母 (GB/T 6170)

nut\_m12 = make\_hex\_nut(D=12, P=1.75, s=18, m=10.8)

cq.exporters.export(nut\_m12, "M12\_hex\_nut.step")

cq.exporters.export(nut\_m12, "M12\_hex\_nut.stl")

```



如果需要精确的螺纹几何，可以使用`cq\_warehouse`库的`fastenerNut`类：



```python

from cq\_warehouse.fastener import HexNut

```



\### 4.4 使用AI生成螺母模型的完整工作流程



1\. \*\*确定规格\*\*：明确螺母的类型、标准号、螺纹规格和性能等级

2\. \*\*查阅尺寸表\*\*：从标准表格或上述数据中获取s、e、m等关键尺寸

3\. \*\*编写Prompt\*\*：使用上述模板，将尺寸参数填入

4\. \*\*AI生成代码\*\*：AI输出CadQuery/FreeCAD Python代码

5\. \*\*运行验证\*\*：在本地Python环境运行代码，检查模型是否正确

6\. \*\*迭代优化\*\*：根据结果调整参数或修改Prompt，如增加倒角、螺纹细节等

7\. \*\*导出使用\*\*：输出STEP用于CAD/CAM，或STL用于3D打印
